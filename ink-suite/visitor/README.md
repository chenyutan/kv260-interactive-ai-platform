# 游客画卷与山河榜

2026-10-03：按用户决定，本版仅局域网可用。`Portal.start()` 只启动本地下载服务，不加载旧 `public-site.json`、不启动公网上传、不使用公网二维码。旧配置与同步历史留存，不改变已有游客数据。无需云端密钥、Netlify账号或互联网；手机离开板卡所在热点后无法继续访问，已下载图片仍可保留。

主菜单两侧直接提供“扫码下载”和“结束游玩”。两个入口同时支持鼠标与原有右手两秒停留。下载页的本次游客二维码每五秒重新检查 Wi-Fi 地址；只选无线接口，不会把电脑以太网地址当成手机热点地址。无无线地址时显示连接提示，游戏与画卷仍保存在板卡。

手机与 KV260 连接同一个 Wi-Fi 或手机热点后访问板卡 `8091` 端口。每次会话有 256 位随机私密链接。手机页面可以为游客命名、下载国风 PNG 战绩长图、多页战绩图片 ZIP、本次画卷原图、HTML 成绩报告、CSV 成绩表、JSON 记录和含画作与报告的完整礼包。HTML 报告可用浏览器打印为 PDF。原 ConnectedGallery 的 `8090` 服务和历史作品二维码保留。

游客数据默认保存在套件 `data/visitors/`，SQLite WAL 保留当前会话、完成及中断局，原图另存不可变文件。宿主正常退出和异常重启都不会结束游客或清画卷。重新启动恢复同一游客链接；上一进程的未完成局记为中断。游戏进程每秒异步保存计数器；完成或离开游戏时，先同步持久保存终局意图，再异步入库。退出最多等待三秒，若数据库仍忙，终局意图留在本地文件，宿主归档前或重启时重放；不会因为等待到期丢弃终局。离线预览与诊断不会写游客成绩。手机没有提交成绩或结束游玩的接口。

“结束游玩”再次确认后，宿主暂停并关闭当前游戏，保存最终水墨画、生成并校验完整归档包；成功后才调用现有画卷清理接口，再归档会话并创建下一位游客。已有原图、成绩与排行榜保留，原游客链接继续可命名与下载。归档失败保留画卷。清理回执丢失时通过空画卷确认完成；若中断后画卷已发生变化，则停止自动清理并提示检查。重启只恢复先前已经确认并持久保存的结束操作。

排行榜只收板卡游戏进程写入的完成局。各游戏单独排名；太鼓按难度、练习段和判定规则分榜，水果按玩法分榜。格斗没有原生总分，排名分定义为胜 10000 / 平 5000 / 负 0，加剩余体力×10、命中×20、完美格挡×30；原始战绩也保留。命名立即反映在报告及历史榜项上。公共排行榜只包含名字、排名分与完成时间，不包含游客私密链接。

测试：在 InkSuite 目录运行 `python -m unittest visitor.test_system`。全部测试使用临时目录和伪画卷后端，不访问生产板卡、不清除用户画作。部署须将 `visitor/` 源码及静态文件一并加入套件闭合清单；二维码使用现有 ConnectedGallery 的离线 qrcode vendor。若防火墙限制端口，需要同网络允许 TCP 8091。

## 操作步骤

1. 在板卡“设备 / Wi-Fi”中连接手机热点，手机保持在同一网络；不需要互联网。
2. 回到主菜单，选择“扫码下载”。本次当前画卷会保存到游客归档，页面显示专属二维码。没有无线地址时按提示连接后选择“刷新二维码”。
3. 手机扫码后输入游客名字并保存。此前已完成的游戏榜项会立即显示新名字；每种玩法在自己的榜单中排名。
4. 下载原图或完整礼包。成绩报告含五个游戏的所有本次局次和关键统计，完成与中断明确区分。游客结束前建议先保留页面链接。
5. 主菜单选择“结束游玩”，再选择“归档并结束”。成功提示后下一位游客从空画卷开始；原游客手机页面显示“已结束游玩”，仍可改名字、下载原图和报告。
6. 若断网或地址变化，重连后从板卡重新扫码；游客链接的私密会话部分保持不变。若归档或画卷清理失败，板卡保留游客会话并提示重试，不把失败当成完成。

主菜单和扫码页沿用现有 Cairo 内存绘制、右手墨迹与停留导航。二维码按整数像素对齐每个模块；低分辨率检查覆盖 640×360、640×420、800×480、960×540 等内部画布，确保二维码不覆盖底部提示。该光栅检查不能代替真实手机对显示器的扫码验收。
