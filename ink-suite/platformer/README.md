# 超级玛丽

原创像素横向闯关小游戏。玩家依次穿过草地、地下通道和城堡，收集金币、顶问号块、踩敌人、跨过断口，最后走进城堡大厅接触公主。三关共用生命；初始3条，收集30枚金币增加1条，最多5条。护盾可抵挡一次碰撞，并允许敲碎普通砖。

## 体感操作

- 右手放在腰腹至下胸的舒适位置。开始时稍停约0.3秒再下压，这次停留的位置就是个人摇杆中心；不必寻找固定中线。向画面左或右摆动约一掌宽即可行走；回到舒适位置或放下右手停止。身体轻移时以身体为参照，左右方向按现有镜像骨架画面识别。
- 左手抬过肩线触发一次跳跃，不要求快速扬手。降到肩线以下后重新准备，下一次过肩可再跳；一直举着不会连续起跳。右手可继续小幅摆动，实现边走边跳。
- 标题页的入场倒计时结束后，右手在当前舒适位置稍停，再向下压确认开始；结算后也这样重开。确认不要求精确回到旧中点，允许小幅横向偏移。一次下压只确认一次，右手先抬回才能再次确认。站稳在可进入的管道上时仍使用回中后下压；其余游戏位置下压不触发确认。重复旧帧、丢点、换人及不合理骨架不能制造确认。
- 右臂转两圈呼出原体验菜单；选择继续后恢复当前关卡。菜单暂停会清掉手势历史，继续后按提示重新回中准备。

左右手独立识别：右手暂时不可见时停止横向移动，左手暂时不可见时停止接收新的跳跃，另一只手仍可操作。骨架数据过期、时间异常或人员切换时清空全部输入，恢复时需重新回中准备。短暂观测缺失不会自动重新倒数或暂停音乐。

详细操作教程统一放在进入游戏前的确认环节。实玩画面只保留生命、金币、关卡和得分；已删除操作说明框和底部教程。识别丢失或手柄断开时保留简短状态，暂停/标题/结算的必要确认状态仍可见。

## 三关路线

第一关“草地”提供安全开场、2格断口和可选高处金币平台；第二关“地下通道”加入上下路线、3格断口和奖励阳台；第三关“城堡”组合3至4格断口和阶梯，经过入口检查点后进入可游玩的大厅。大厅还有最后一道断口和守卫，必须在地面接触公主才算通关，进入城堡或从公主上方飞过不会提前完成。每关有一条管道奖励路线；站上管道确认后到达有实体支撑的平台，收集奖励后落回主路。部分普通砖隐藏5枚金币，实际顶到才领取且不会重复发放。所有奖励都是可选内容。

## 运行与资源

游戏物理、碰撞、像素绘制和音频混音均在 KV260 的 PS/Linux 用户空间运行。游戏不拥有摄像头、不重新加载模型，也不额外创建 DPU 推理链路；只消费套件已有后台发布的最新 COCO-17 骨架。身体识别继续复用已有 DPU 骨架输出。这些职责区分不等于 FPS、显示器扫描输出或真人体感验收已经通过。

角色、景物和面板装饰绘制在 320×180 像素画布，再用最近邻放大到显示区域；960×540 恰为三倍像素，其他尺寸保持比例留边。文字保持清晰的像素风：标题和较大的提示使用两倍整数像素字形；较小的中文说明保留更细的整数像素网格，避免丢失汉字内部笔画。文字使用无抗锯齿的单色字形，按实际字形边界居中。世界与全部文字先在离屏目标完整重画，再通过一次 paint 提交，避免背景刷新与逐条文字叠加之间出现闪字。经验证的完整、未变换 Xlib 目标复用一张原生服务器背板，按 Cairo surface、device 和尺寸绑定；其他上下文使用临时不透明 Cairo group。缩放、特殊裁切、设备变化等情况退回 group，窗口失效时释放背板；绘制失败会丢弃未提交背板，保持原画面。绘制耗时包括背板建立及最终提交，另记建立、提交、复用和释放统计。原生背板最多一张、估计不超过 8 MiB（960×540 约 1.98 MiB），服务器内存估算与 PS 图像缓存分别报告；不缓存 ImageSurface 整帧输出。原创像素角色、景物及程序生成五声音阶音乐随包提供，不从网络下载。静态地形、视差场景、中文说明和 HUD 采用有上限的缓存；文字最多 64 项、6 MiB。

一个 `CubeGameAudioDirector('platformer')` 管理该场景的背景音乐与十种音效：跳跃、拾币、护盾、踩敌、受伤、跌落、管道、检查点、过关、通关。音乐循环；音效不循环。暂停、重开和关闭清掉旧音效队列；结算先清除游戏中的旧音效，再播放本次结果。离线预览禁用真实音频输出。

首次出现的文字使用 Pillow 的 C 实现进行单色 alpha 阈值转换、指定颜色填充与字形边界计算，避免 Python 逐像素扫描造成冷缓存长帧；未安装 Pillow 时保留原循环。两条路径的阈值、ARGB 大小端排列、透明零字节、行尾填充与实际字形边界逐字节等价，像素网格和整帧原生提交方式不变。性能收益仍需板端原生基准确认。

在候选套件根目录可执行：

```text
python3 platformer/main.py --offline-preview
python3 -m unittest platformer.test_engine platformer.test_controls platformer.test_render platformer.test_audio -v
python3 -m platformer.build_audio --verify-only
python3 -m platformer.render --preview contact_sheet.png --benchmark render_benchmark.json
INK_NATIVE_XVFB_TEST=1 xvfb-run -a python3 -m unittest platformer.test_render.NativeXlibOutputTests -v
```

离线预览用左右方向键移动、空格跳跃、回车开始或重开；Esc 呼出菜单。音频校验仅检查文件、SHA-256、PCM 格式和 manifest，对扬声器播放、音量舒适度及现场音画同步不作验收结论。

## 2026-10-17 内容验证

- `python3 -m unittest discover -s platformer -t . -q`：覆盖物理、输入、生命周期、音频、绘制与内容回放。
- `platformer/test_content.py`：从第一关出生点开始，用真实 move/jump 输入完成三关与公主接触，再以录制输入独立回放并逐状态比对；没有传送玩家、关闭敌人或增加无敌。管道与隐藏砖测试另设局部场景，验证真实起跳、碰撞、确认、出口落地及一次性奖励。
- `platformer/qa_content.py --project <ink-suite路径> --output <E盘证据目录> --previews`：导出主机离屏耗时、五张明确标记的布景预览，以及真实完整回放的通关静帧和RLE输入。
- 使用既有缓存背景/图集/地形块，城堡大厅为启动时生成的640×160静态条带。新增每帧实体仅公主与检查点；输入映射、固定步长和跳跃参数均未改动。
- 内部主题键 `bamboo/temple/moon` 为兼容旧场景快照保留，对应当前草地/地下/城堡。内部敌人键 `lantern` 对应原创甲虫图像。
- 主机离屏测试不等于KV260帧率、真实摄像头、手柄或人工体验验收；部署前另做板端抽检。
