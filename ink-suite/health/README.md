# 八段锦与二十四式太极指导

健康板块有八段锦、二十四式太极两个独立入口。八段锦含预备式、传统八式和收势；太极按完整二十四式顺序，含起势、收势与两次单鞭。每式先看真人视频，再进入骨架示意与跟练，按实际可见关节给出有限建议。传统名称仅标识功法，不表示软件能治疗或预防疾病。

## 流程与接口

宿主用 `HealthView`、`LessonVideoFlow`、`TeachingVideoPlayer` 协调视频。结束/跳过后，分解学习先看一周期轮廓示意再跟练；完整跟练直接显示示意和观测骨架并按课程时钟前进；自主练习自行决定换式。每次换式都有对应视频，跟练中可回看。

观看时暂停 `LessonSession`，不增加练习秒数或计数。暂停/重看/换式/退出清理旧媒体状态，加载错误提供重试与“看示意并跟练”。丢点不会自动暂停课程。计时结束不代表技术动作合格。

欢迎页、视频页和跟练页都有“选择动作”。太极每页12式、共两页，八段锦一页；可直接选择任一式，不必连续跳过前面的课程。选式期间暂停计时，返回原页时保留先前的播放/暂停状态。欢迎页选好动作后，再选择练习方式开始。

手柄方向键选择按钮，A确认。B按页面逐级返回：选式/记录页返回原页，练习中先暂停，再按B回到课程欢迎页并保存记录，欢迎页B返回健康板块；Guide退出当前课程。Menu仍用于暂停/继续。回看视频不会把原已暂停的练习自动恢复；隐藏、最小化或退出课程同样停止练习计时。

纯课程仍可独立使用：

```python
from health.engine import LessonSession
session = LessonSession(mode='learn', course_id='taichi')  # 或 baduanjin；learn / follow / free
session.start()
frame = session.update(api_state)     # 元数据，不请求摄像头图像
session.action('pause')
session.action('play')
session.action('next')                # previous / repeat / finish
session.action('select_cloud')        # 按当前课程动作ID直选；保留原暂停状态
report = session.report()
```

课程核心不解码视频，UI媒体协调器负责视频阶段。原创骨架轮廓尚未经过专业指导员复核，不冒充视频教练的标准动作数据。

## 视频、来源与音频

10段八段锦真人教学来自[深圳市文化广电旅游体育局专栏](https://wtl.sz.gov.cn/ztzl_78228/tszl/wlzgj/bdj/)，按[非商业转载条款](https://wtl.sz.gov.cn/fzlm/bqbh/index.html)保留出处。已逐段去除18–31秒无动作片头，合计269秒，保留正式讲解、示范、细节和纠正。具体边界和原始/处理后哈希见 `assets/video/manifest.json`，出处见 `assets/video/attribution.md`。

太极真人示范来自[北京理工大学公开视频下载页](https://opt.bit.edu.cn/zlxz/b58242.htm)，按24式边界分段；每一式对应一段实际真人演练，细节由应用文字和骨架示意补充。它不是24段独立分解讲解。完整顺序、来源与时间边界见 `assets/taichi-video/manifest.json` 和 `assets/taichi-video/attribution.md`。

两套媒体全画面等比例转码、必要留边，VP8/Vorbis、640×360/25FPS，保留原声及画面署名。限定本项目本地非商业学习，不随公开GitHub源码上传。原始媒体保存在本任务E盘工作区，应用只含播放用文件。

GStreamer状态切换及解码由单一工作线程执行；前台Cairo只取最新640×360帧，不积压整片。原声仅走显式Cube路由，没有有效设备时静音继续；视频期间停用应用短口令。太极跟练使用文字指导，不播放八段锦口令。

## 建议与观察范围

`AdviceObserver` 根据连续实际坐标选择一条稳定提示、限制切换频率并返回相关关节。UI可突出这些关节。具体包括双手上托持续高差、侧展手腕偏离肩线较多、单举时双腕均抬高，也可确认上举、侧展、回收、双腕下降。

不根据动画时刻强迫用户追进度，不要求统一幅度或极限。具体姿势建议需要较可靠的连续关节；低置信度可保留骨架显示但不作姿势纠正。缺点/遮挡/出框先提示取景，不当作动作错误。过期/重复/倒退帧、服务重启或历史中断清除旧建议和未完成计数，不补造坐标。

- 托天、开弓、单举：观察图像平面内手臂展开与回收。
- 摇头摆尾：只观察躯干平面位移，不判断真实重心、头转或脊柱。
- 两手攀足：只观察双腕下降/回升，不评价腰椎，不要求触足。
- 回望、攒拳、提踵：缺少可靠头颈朝向、前推深度/掌型、脚跟脚尖信息，不作对应技术评分或次数判断。
- 预备与收势：入镜和流程引导。

太极只给出可见双腕高低、手臂侧展、膝踝入镜等二维提示；不自动计完整动作次数，不判断掌型、发力、呼吸、重心和动作是否专业合格。骨架为原创方向示意，以真人示范为准。下势、蹬脚等动作不追求深度或高度，可自行跳过。

输入是17个归一化槽位 `[x,y,score]`；并非模型直接输出17类关节，当前身体观测使用5–16槽。`timestamp_seconds` 与本机单调时钟一致，带 `pid` 和递增 `sequence`。

## 记录与保存

只保存时长、可观察时间、八段锦有限往返计数及访问情况，不保存人像、逐帧骨架、热量、医学结论或统一健康分数。视频另记打开/跳过/播放到末尾的式子，观看不计练习时间。太极报告使用 `taichi-<会话ID>.json` 与 `taichi_practice` 类型，课程历史各自隔离，原八段锦格式兼容。

`save_report(directory)` 使用同目录临时文件、fsync和原子替换。失败后界面保留首次报告快照，显式重试 `save_report(directory, report=frozen_report)`，不追加失败后的时间/次数。离开后可复入重试，期间不计时；拒绝NaN/Infinity和不同会话快照。

## 依据与验证边界

名称/顺序参考体育总局[八段锦定式动作](https://www.sport.gov.cn/n20001280/n20001265/n20067611/c20106840/content.html)，舒适幅度原则参考[老人习练健身气功需从自身实际出发](https://www.sport.gov.cn/n20001280/n20001265/n20066978/c30109457/content.html)。未复制这两个页面的图片/音频，真人视频另有上述来源。

核心测试可从应用根执行 `python -B -m unittest health.test_engine health.test_advice health.test_media_flow -v`，使用合成坐标/假时钟。实际GTK和视频测试需本地GTK/GStreamer，最终结果以任务QA收据及发布清单为准。

软件测试不证明真人准确率、专业动作合格或临床效果。部署和自动验证结果以本次任务交付记录为准；真人跟练与物理音响听感仍需单独验收。
