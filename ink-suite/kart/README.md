# 赛车

原生 GTK3 + 独立 GLES2 真3D 赛车。960×540，以已有 EGL 完整帧单次交换后端展示封闭山水赛道；后端不可用时明确报告 Cairo 2.5D 应急渲染。全部几何在本地生成，无浏览器。

## 运行与编译

```sh
python3 -B kart/native/build_native.py --output kart/native/libracer3d.so
python3 -B kart/main.py --offline-preview --size 960x540
python3 -B kart/main.py --offline-preview --benchmark 90 --metrics /tmp/kart-metrics.json
python3 -B -m unittest kart.test_core
```

编译需要系统 C++17、EGL/GLES2 头文件与 `libdl`；板端头路径 `/usr/include/mali`。库 ABI 只传递标量快照，与 runner 角色/材质 ABI 独立。

主机协议与 runner 一致：`--embed-socket`、`--base-url`（亦接受 `--pose-url`）、`--entry-delay`、`--fullscreen`、`--size`、`--metrics`；stdin 接收逐行 JSON `pause/resume/shutdown/action`，stdout 输出 `ready`、`menu_requested`、动作回执和本局结果。暂停、输入世代、恢复清输入和新鲜度逻辑沿用已有原生游戏框架。游戏不拥有摄像头或推理实例。

## 游戏规则

约 790.49 米封闭赛道，玩家加 5 位 AI，3 圈结束。自动加速，身体左右倾或双手模拟方向盘转向；左手抬起并转向漂移，放下后按蓄力获得小加速；右手抬起使用已持有道具；双手到肩线持续约 0.3 秒开始。道具依次为加速、单次护盾、可见追踪弹。碰护栏减速，碰其他车轻微挤开。已完赛 AI 保留成绩后继续驶离终点，避免停在赛道中。

2026-10-19 B 版：节庆街屋、连续竹林弯和湖湾石拱桥组成三段连续空间，四米平滑桥坡与镜头/车辆俯仰共享同一采样表，湖岸有下沉石岸和转动水车。草地、水面、山体使用分块顶点色；512×512 原创图集只用于道路外侧窄铺面，flat/textured 网格分离，远景保留几何并切换到无纹理着色。保守 AABB 视锥剔除可用 `INK_KART_CULL=0` 单变量关闭以核对截图。主车与14米内车辆保留旋转轮组/独立车手，远车使用外轮廓差小于0.06米的合并模型；树竹保留近远几何级别。

赛车采用平滑顶点光照、分层宽胎与轮毂、独立车手倾斜与软边接触阴影。镜头按速度与加速缓动。漂移蓄力达到 0.65 / 1.25 / 1.95 秒分别进入蓝焰、金焰、紫焰，松开产生 0.80 / 1.40 / 2.05 秒加速。六组道具各提供三条可选择路线。拾取、护盾破裂、受击和漂移释放有短时扩散环。六车碰撞每子步最多四轮有界纠正。

原生 C ABI 结构大小与版本保留为 v1。仅 `drift` 标量在 Python/C++ 内部约定为 `方向 × (1 + 蓄力秒数)`；引擎快照仍分别提供 `drift` 和 `drift_charge`，宿主输入、暂停、重开、结果和音频接口不变。

手柄：左摇杆转向，B/LB 持续漂移，X/RB 使用道具，LT/下方向刹车，A 开始或重赛。START 归宿主菜单管理。离线键盘：左右或 A/D 转向、Shift 漂移、空格/X 道具、下/S 刹车、回车开始、Esc 请求菜单。

完成积分 = `(6 - 名次) × 100000 + max(0, 60000 - floor(用时秒 × 100)) + 本局道具/漂移奖励`。名次优先，再比较时间。未完成局只保留进度，不视为完整比赛成绩。

## 验证边界

`test_core.py` 是 CPU 物理、输入新鲜度、暂停恢复、道具、完成排名测试。离线 benchmark 是确定性自动驾驶场景，不能代表真人体感接受或物理屏幕扫描。实际 GLES2、Mali 性能与宿主集成由同日板端验证收据记录。

F 独立美术候选：侧墙四色明暗与梁窗、七孔椭圆石拱、低频草地色带、16侧近树冠，原创头盔眼白/瞳孔及贴合赛车条；远车同步条纹。金色火花与引擎/HUD统一1.25秒门限。保持既有相机、玩法、道具数量和FX。
