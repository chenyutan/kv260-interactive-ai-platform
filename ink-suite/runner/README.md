# 地铁跑酷 · 国风三轨跑酷

采用经典三轨跑酷规则：角色自动前进，换道避开货车，跳过矮栏，滑过灯笼门；拾取铜钱、聚宝磁铁和护身符。三次受伤后结算，前进距离增加时逐渐加速。每波留有空道，铜钱引导可通行路线。

## 操作

- 自然站立片刻后，身体向左或右侧移：换一条道；每次回到原来的自然站立中心后，可再次侧移。左右按镜像画面方向。
- 身体实际向上起跳：角色跳跃；落地回到自然站立后可再次跳。挥手或举手不会触发跑跳。
- 身体轻轻下沉：滑铲，肩与髋均需入镜；恢复自然站立后可再次滑铲。
- 标题或结算页双手举过肩约半秒：开始或再来一局。无需手腕回到精确中间位置。
- 右臂转两圈：沿用系统二级菜单，可暂停、继续、重开、调音量或回主菜单。
- 键盘备用：左右箭头换道，空格/上箭头跳跃，下箭头滑铲，回车开始；Esc 呼出菜单。标题与结算页也可点击开始。

双肩和双髋必须入镜；运行时无需手腕可见。身体中心会在约0.24秒的稳定姿态中自动捕获，无需对准屏幕上的精确点。下蹲后的起身只用于恢复，不会误当起跳；跳跃落地时的屈膝有恢复保护，避免接出滑铲。

短暂骨架缺失只抑制新的动作，不弹摄像头断连提示或反复倒计时；持续失去有效输入约 1.25 秒才保留旅程，识别恢复后继续。收到单人追踪元数据时，仅在`input_allowed=true`且身份字段完整时接收身体输入；锁定用户或epoch变更后重新捕获中心，第一帧不触发动作。

## 实现与性能

原生 GTK3/Cairo，固定 960×540 内部绘制，等比例输出；图像缩放和字形缓存启动时预热，画面在内存中完整合成后一次性上传，避免 X11 命令积压。按真实 visual 色深选择 RGB565 或 RGB24。精灵、字体、特效和输入队列有界。物理逻辑按真实时间推进并细分碰撞步长，绘制不会改变游戏速度。摄像头与人体推理沿用共享服务，只取最新 COCO-17 状态，不新开相机或模型。

音频是本地生成的原创 32 秒五声音阶拨弦、笛音与轻鼓循环，7 种事件音效。48 kHz、立体声 PCM16，总缓存约 6.4 MiB，运行时不合成音乐；使用系统已经验证的 Cube 输出和故障恢复路径。

成绩含得分、距离、铜钱、时长与动作计数，接入访客系统、排行榜和战绩图片下载。重开生成新的独立局记录。
